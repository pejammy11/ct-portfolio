Project 2: Data Analysis

Reflection

During term 2 of Computing Technology, we studied data analysis and learnt about data processing and presentation. Mr Lo Russo taught us how to use google spreadsheets to present datasets in a visually appealing and easy to understand way. We were given a class task to write an article analysing data of our choice from google trends. I wrote about a topic of my interest, politics and I used search trends to compare how people's searches line up with their vote and the media coverage of events concerning certain candidates/parties. You can read it by clicking the link below:



The Two-Party System- Do You Google Your Vote?



For this data analysis project, I used a large data set in Google Sheets of the most played songs on spotify to build a statistics dashboard. We learnt how to sort the data by different values and how to work spreadsheets before using the spreadsheet features to organise the information. I was absent for some of the lessons, but still managed to complete part of my dashboard, as shown here.



The best part was using the dashboard tool to turn those long lists of numbers into visual charts. I also chose a clean color scheme so the whole page looked professional instead of crowded. This project taught me how to use spreadsheet tools to make data look simple, readable and visually pleasing. In the end, it was cool to see a giant wall of confusing numbers turn into a clean, visual dashboard that actually makes sense at a glance.
